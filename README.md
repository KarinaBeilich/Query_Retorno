## 🔎 Visão Geral

Este projeto foi desenvolvido para otimizar e garantir a confiabilidade do processo de conciliação bancária. A ferramenta realiza o cruzamento de dados automatizado para identificar falhas comuns no fluxo financeiro/operacional, tais como:
* **Duplicidade de registros:** Identificação de retornos que foram processados mais de uma vez.
* **Divergência de processamento:** Auditoria entre o arquivo de retorno oficial do banco e o que foi efetivamente computado de forma automática pelo sistema interno.

O objetivo principal é mitigar erros manuais, centralizar os scripts de consulta e fornecer uma planilha modelo funcional e pronta para uso.

---

## 🚀 Funcionalidades

* **Automação via VBA:** Macros estruturadas para limpeza, tratamento e cruzamento dos relatórios de forma rápida.
* **Query de Retorno Duplicado:** Lógica de consulta estruturada para localizar gargalos e repetições nas movimentações.
* **Batimento Automático:** Relatório comparativo que aponta exatamente quais registros estão integrados e quais apresentam divergências (banco vs. sistema).
* **Planilha Base Estruturada:** Modelo pronto para importação dos dados brutos e execução das rotinas.

---

## 🛠️ Tecnologias Utilizadas

* **Microsoft Excel & VBA (Visual Basic for Applications)** - Para a construção da interface de usuário, automações e lógica de batimento.
* **SQL / Queries de Banco de Dados** - Para a extração, filtragem e refinamento dos dados de retorno.
